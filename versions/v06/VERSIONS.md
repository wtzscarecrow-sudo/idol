# 灯下偶戏 · 版本与回退

| 版本 | 内容 | 本地入口 |
| --- | --- | --- |
| v03 | 五幕巡演，十五只木偶与旧版资源规则。 | [打开 v03](http://127.0.0.1:43181/versions/v03/) |
| v04 | 五个流派，三十只木偶与新版台面资源。 | [打开 v04](http://127.0.0.1:43181/versions/v04/) |
| v05 | 所有木偶有固定基础喝彩，技能改成图标和短词。 | [打开 v05](http://127.0.0.1:43181/versions/v05/) |
| v06 | 调整五派开局资源供应，重设部分数值。 | [打开 v06](http://127.0.0.1:43181/versions/v06/) |

在项目目录运行 `python scripts/local_site.py`。根路径播放当前工作版，每个版本目录都包含可独立运行的网页和本地资源。旧版和新版使用各自的浏览器存档，访问同一台电脑的同一端口时，可以分别续玩。

每版完成后，从项目目录运行 `python scripts/local_site.py --backup v07`，按实际版本号替换 `v07`。脚本复制网页和设计记录，校验文件哈希，并拒绝覆盖已有快照。把对应的新快照和代码提交到 Git，已有 GitHub 备份仓库时再推送。版本快照只包含项目文件，玩家进度保存在各自浏览器中。

直接试玩历史版时，可以打开上表链接。需要在旧版上继续开发时，将对应版本的 `dist` 复制到单独的开发目录，再从那里启动静态服务器。
